# Схема даних пам'яток

Файл даних: `src/Data/literaryObjects.js`, масив об'єктів.
Допустимі `type` і `category` задані в `src/Data/schema.js` і є єдиним джерелом для маркерів, легенди, фільтрів і перевірки.

Перевірка: `npm run check-data`.

## Поля

| Поле | Тип | Обов'язкове | Опис |
|---|---|---|---|
| `id` | число | так | Унікальний ідентифікатор |
| `name` | рядок | так | Назва пам'ятки |
| `type` | ключ | так | Тип пам'ятки, один із ключів у таблиці нижче |
| `subtype` | рядок | ні | Детальний український опис типу, наприклад «Меморіальний музей» або «Музей просто неба» |
| `category` | ключ | так | Тематична категорія, один із ключів у таблиці нижче |
| `person` | рядок | ні | Людина, група людей або явище, з якими пов'язана пам'ятка |
| `city` | рядок | ні | Населений пункт |
| `region` | рядок | ні | Область або історичний регіон |
| `country` | рядок | так | Країна (українською) |
| `lat`, `lng` | число | так | Координати (WGS84) |
| `year` | ціле число або `null` | ні | Рік встановлення, відкриття чи будівництва пам'ятки. Від'ємне значення означає рік до н. е. |
| `openingDate` | рядок | ні | Точна дата відкриття |
| `eventDate` | рядок | ні | Дата або період події, з якою пов'язана пам'ятка (текстом) |
| `description` | рядок | так | Короткий опис |
| `history` | рядок | ні | Історична довідка |
| `significance` | рядок | ні | Значення пам'ятки |
| `author` | рядок | ні | Скульптор або автор |
| `architect` | рядок | ні | Архітектор |
| `images` | масив | ні | `[{ url, author, license, sourceUrl }]`, фото з Wikimedia Commons з автором і ліцензією |
| `videos` | масив | ні | `[{ title, url }]`. YouTube вбудовується в модалку, інші посилання показуються як лінки |
| `sources` | масив | бажано | `[{ title, url }]`, джерела фактів |

Застарілі поля `imageUrl`, `videoUrl`, `sourceUrl` і `video` заборонені: перевірка їх не пропустить.
Посилання на `example.com` і `images.openai.com` також заборонені.

## Типи (`type`)

| Ключ | Назва | Форма маркера |
|---|---|---|
| `monument` | Пам'ятник | коло |
| `memorial` | Меморіал | зірка |
| `plaque` | Меморіальна дошка | горизонтальний прямокутник |
| `museum` | Музей | ромб |
| `grave` | Могила | хрест |
| `university` | Навчальний заклад | квадрат |
| `theatre` | Театр, концертна зала | трикутник |
| `castle` | Замок, фортеця | вежа із зубцями |
| `archaeological` | Археологічна пам'ятка | шестикутник |
| `historical_site` | Історичне місце | восьмикутник |
| `building` | Історична будівля | будиночок |
| `park` | Парк, сад | листок |
| `film_location` | Кіно: студія, локація | паралелограм |
| `industrial` | Промислова пам'ятка | трапеція |

## Категорії (`category`)

| Ключ | Назва |
|---|---|
| `literature` | Література |
| `music_theatre` | Музика й театр |
| `cinema` | Кіно |
| `art` | Мистецтво й архітектура |
| `science` | Наука, освіта й техніка |
| `ancient` | Археологія й давня історія |
| `cossack` | Козацтво, замки й фортеці |
| `independence` | Державність і визвольні змагання |
| `tragedies` | Війни, трагедії й пам'ять |
| `folk` | Музеї й народна культура |

## Приклад

```js
{
  id: 1,
  name: 'Пам’ятник Тарасові Шевченку',
  type: 'monument',
  category: 'literature',
  person: 'Тарас Шевченко',
  city: 'Київ',
  country: 'Україна',
  lat: 50.4423,
  lng: 30.5144,
  year: 1939,
  description: '…',
  images: [{ url: 'https://upload.wikimedia.org/…', author: '…', license: 'CC BY-SA 4.0', sourceUrl: 'https://commons.wikimedia.org/wiki/File:…' }],
  sources: [{ title: 'Вікіпедія: Пам’ятник Тарасові Шевченку (Київ)', url: 'https://uk.wikipedia.org/wiki/…' }]
}
```
